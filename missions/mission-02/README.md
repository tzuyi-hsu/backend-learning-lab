# Mission 02 Reflection

1. 這個 Mission 我學會了什麼？
- 這個 Mission 主要讓我更清楚資料流，以及如何取得資料、拆分需求。以前有些做法是憑直覺，這次發現其中有不少錯誤。

2. 我現在怎麼判斷一個需求要不要拆成多個 function？
- 我會依照不同的工作責任去區分，讓每個 function 負責較單一的工作，提升可讀性與維護性。

3. function 的參數、return、呼叫端之間，資料怎麼流？
- 呼叫 function 時把需要的資料透過參數傳入，function 執行處理後用 return 把結果傳回呼叫端，再用變數接住結果並繼續使用。

4. 我目前最容易犯的錯誤是什麼？
- 寫得比較快時，容易忘記 function return 之後還需要由呼叫端用變數接住回傳值。不過經過這次 Mission 的練習後已經熟悉許多。
